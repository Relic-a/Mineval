# Mineval

Mineval prepares historical coding tasks from real repositories, benchmarks exact frozen revisions, and records independent private evaluations and evidence-backed model observations. Its users operate a trusted local developer workspace.

The historical UI has seven destinations: Overview, Tasks, Benchmarks, Models, Activity, Web Arena, and Settings. Preparation, tested model selection, and evaluation/review defaults are separate responsibilities. Existing durable queues, immutable receipts, evaluation behavior, model discovery, and model memory are authoritative.

The visual direction is pinned by the supplied reference: dark, compact, restrained developer tooling in the tradition of Linear, Vercel, Better Auth and Resend. Operational clarity and real data take precedence over decorative expression. Arena's embedded historical views are read-only; only the standalone trusted observe server enables historical mutations.
